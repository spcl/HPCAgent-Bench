# HPCAgent-Bench dependency list (hand-maintained).
# The two framework baselines with platform-install friction (apache-tvm, mpi4py) live
# in requirements/optional.txt so this file installs cleanly everywhere, incl. macOS
# arm64. The container images install optional.txt on top (see containers/cpu.def).
numpy>=2,<3
scipy
pandas
matplotlib
ml_dtypes
pygount
pyyaml
jsonschema
# Declared in setup.py install_requires; the CE images install only this file (the repo is
# MOUNTED, never pip-installed), so a miss here is a judge ModuleNotFoundError at first grade.
sympy
blake3
setuptools
# Typed results-DB schema layer (hpcagent_bench/frameworks/schema.py).
sqlmodel
jinja2
cffi
tree-sitter-language-pack
psutil
py-cpuinfo
GPUtil
# dace is NOT the PyPI wheel (an old release that imports the numpy-2-removed
# ``np.int`` and fails under numpy>=2) -- the container clones spcl/dace@extended
# editable with submodules, mirroring .github/actions/setup. See the Dockerfile.
# ordered-set is a dace runtime import (dace/sdfg/graph.py et al). dace@extended added the
# import before declaring it in install_requires, so a fresh editable clone briefly shipped
# without it and every dace-importing job died on ModuleNotFoundError. Declare it here too so
# a gap in dace's own dep list can never silently drop it again.
ordered-set >= 4.0.0
numba
pythran
jax
xgboost
torch
# HDF5 / netCDF bindings for the apt libhdf5-dev + libnetcdf-dev the images install.
# Declared EXPLICITLY: they used to arrive only as a transitive dep of the stock PyPI
# dace, so pinning dace to the fork (which does not depend on them) silently dropped
# them and the image smoke test -- which imports both -- broke. A dep the smoke test
# asserts must be a dep this file states.
h5py
netCDF4
