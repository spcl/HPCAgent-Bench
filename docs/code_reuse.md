lives. "Before" locations are `file:line` at commit `020bfca44` (paths relative to `hpcagent_bench/`
unless they start with `agent/`, `tests/`, `containers/` or `helpers/`). **Consolidated** rows were merged in the reuse pass that
added this page. **Proposal** rows are not merged yet; the helper column names the proposed home.
**Kept** rows were checked and left alone on purpose; the row says why.

A second review at commit `934c5b98d` re-checked every proposal row. Rows still open carry their
locations at that commit in a trailing "At `934c5b98d`" note, and the duplications it found anew are
in [Found by the second review](#found-by-the-second-review).
